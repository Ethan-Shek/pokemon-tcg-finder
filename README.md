## Pokémon TCG Finder

- Built with **React** (JavaScript)
- Styled using **Bulma CSS Framework**
- Data fetched from **Pokémon TCG API**

## Technologies Used

- **Language**: JavaScript (ES6+)
- **Framework**: React (with React Router)
- **Styling**: Bulma CSS Framework + custom CSS
- **Bundler**: Vite
- **API**: Pokémon TCG API (https://pokemontcg.io/)
- **Package Manager**: npm


### Card Search
- Search Pokémon cards by name
- Filter by rarity: Common, Uncommon, Rare
- Clear button resets search and filter instantly

### Responsive Design
- Built with Bulma for fully responsive layouts
- Mobile-friendly card display with multi-column support

### Card Display
- Dynamically loads card images, names, and rarity
- Cards styled with bold colors and themed visuals
- Unique card border and hover styles for pop

### Navigation
- SPA with React Router
- Clean routing between **Home** and **About** pages
- Navigation bar with centered buttons
